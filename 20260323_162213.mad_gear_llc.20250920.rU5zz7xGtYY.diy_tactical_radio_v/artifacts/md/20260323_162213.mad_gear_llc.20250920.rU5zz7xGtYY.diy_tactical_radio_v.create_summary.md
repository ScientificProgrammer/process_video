# ONE SENTENCE SUMMARY:

Open MANET is an affordable open-source alternative to expensive military mesh networking radios for community resilience applications.

# MAIN POINTS:

1. Military-grade MANET radios from Silvus and Persistent Systems cost over $20,000 with proprietary waveforms and ecosystems.
2. High-end systems feature anti-jam capabilities, low probability of detection, and military-grade encryption for contested environments.
3. Most civilians don't need expensive military features designed for adversarial situations requiring specialized security measures.
4. Open MANET provides a DIY recipe using OpenWRT software and Batman Advanced routing protocol for affordable solutions.
5. The project uses Raspberry Pi hardware with Wi-Fi HaLow operating at 900 MHz for extended range.
6. Open MANET delivers 1-15 megabytes per second, sufficient for pictures, maps, data, and video streaming.
7. Military systems offer hundreds of megabytes throughput, IP68 enclosures, and support for hundreds of nodes.
8. Open MANET costs approximately $100 versus five-figure military alternatives, democratizing mesh networking technology for communities.
9. Batman Advanced enables self-healing mesh networks that automatically reroute traffic when nodes fail or move.
10. The open-source community relies on volunteers developing solutions in spare time without dedicated funding.

# TAKEAWAYS:

1. Community resilience networks can be built affordably without requiring expensive military-grade MANET radio systems.
2. Wi-Fi HaLow at 900 MHz provides mile-range coverage with better wall and foliage penetration.
3. Open MANET's GitHub repository offers free access to all necessary documentation and implementation guides.
4. Standard Wi-Fi security proves sufficient for civilian applications unless facing nation-state level threats.
5. Open-source development democratizes technology access but requires community contribution to sustain progress and innovation.
