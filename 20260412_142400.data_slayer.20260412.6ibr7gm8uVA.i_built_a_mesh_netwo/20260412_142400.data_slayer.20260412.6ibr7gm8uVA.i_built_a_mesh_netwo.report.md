# Reticulum Network Range Testing: Building an ISP-Free Internet

## Overview

This video documents an extensive real-world testing series of Reticulum, an open-source internet protocol that enables network communication without traditional ISPs. The creator progressively tests the protocol's range capabilities—from across a house to across continents—using various radio technologies including WiFi HaLow and LoRa, ultimately demonstrating that decentralized mesh networking could provide a viable alternative to centralized internet infrastructure.

## Initial Setup and House Test

**[00:00:00] The Challenge**
- Goal: Send messages using only the Reticulum network, no traditional ISP dependency
- Test progression: House → Neighborhood → City → International
- Core principle: Building a parallel economy of open-source, decentralized, affordable tech

**[00:03:15] Hardware Configuration**
- **Base node**: Green Haven node (Raspberry Pi running OpenMana fork of OpenWrt)
- Features sub-gigahertz 900MHz HaLow chip for extended range
- Bridges WiFi, Ethernet, and HaLow interfaces
- **Client setup**: MeshChat application running RNS (Reticulum) service

**[00:06:30] Mobile Node Setup**
- Helltech HD-T01 board running OpenWrt with HaLow radio

**[00:11:45] First Messages Sent**

## City Test Attempts

**[00:23:00] The Challenge Escalates**
- Target: Send messages to neighboring city (approximately 4 miles)
- Initial attempts using WiFi HaLow with kite-mounted aerial node
- **Issue**: Intermittent connectivity—node would spot base station briefly then lose connection

**[00:25:15] Pivot to LoRa Technology**
- HaLow limitations in residential setting without high altitude advantage
- **LoRa advantages**: 
  - Operates below noise floor
  - Better obstruction penetration
  - Adjustable parameters (coding rate, spreading factor, bandwidth)
- Trade-off: Lower bandwidth but superior range characteristics

**[00:28:40] LoRa Configuration**
- Two Helltech v4 boards running 27 dBm transmit power
- **Parameters optimized for range**:
  - Bandwidth: 125 kHz
  - Spreading factor: 12 (maximum)
  - Coding rate: 8
- Ping script sends automatic connection test every 60 seconds

**[00:30:00] Straightaway Test Results**
- **0.5 miles**: Ping 26 received (RSSI: -44, SNR: 5 dB)
- **1 mile**: Ping 27 received (RSSI: -85, SNR: -3.2 dB)
- **1.5 miles**: RSSI -92, SNR 3.2 dB
- **2 miles**: Ping 68 (RSSI: -91, SNR: 4 dB)
- **3.4 miles**: Signal maintained (SNR: -6.2 dB)
- **Maximum range**: 3.5 miles with line-of-sight on flat road

**[00:33:20] Key Findings**
- Line-of-sight proved more critical than elevation for LoRa
- Metal structures act as Faraday cages, blocking signals
- Urban reflection less effective than anticipated
- Node wasn't elevated—just on tripod at ground level
