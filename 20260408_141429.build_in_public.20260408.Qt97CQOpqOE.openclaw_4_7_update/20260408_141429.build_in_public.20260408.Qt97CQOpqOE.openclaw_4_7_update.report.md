## Executive Summary

Open-Claw 4.7 represents a fundamental upgrade transforming AI agents from experimental tools into production-grade infrastructure through Memory Wiki, webhooks, and reliability features. The creator strongly advises careful evaluation before upgrading, as version updates can break existing pipelines despite powerful new capabilities.

**Memory Wiki** replaces flat file storage with structured knowledge management featuring claim-evidence fields, contradiction clustering, staleness dashboards, and freshness-weighted search. This transforms memory from simple storage into intelligent knowledge management, enabling agents to identify outdated information and recognize contradictions.

**Open-Claw Infer** provides unified CLI access to model tasks, media tasks, web tasks, and embeddings, collapsing multi-day integration projects into single commands.

**Webhooks** enable external systems (Zapier, Stripe, GitHub, CRMs) to trigger agent workflows through secure endpoints, transforming agents from isolated tools into integrated workflow participants responding to real-time events.

**Session Branch and Restore** creates compaction checkpoints using session UUIDs, enabling recovery from any pre-compaction state and preventing hours of work from evaporating.

**Enhanced Memory Dreaming** ingests redacted session transcripts with per-day corpus notes and cursor checkpointing, producing more accurate memories that compound automatically overnight.

**Media Generation Auto Fallback** provides automatic failover across image, music, and video providers with size and aspect ratio remapping, eliminating manual intervention during service outages.

**New model support** includes Gemini 4, Akri AI, and Llama Vision (enabling fully local, private vision processing without external API calls).

**Plugin Compaction** allows custom summarization providers for domain-specific optimization of how agents preserve knowledge.

**System Prompt Override** enables safe prompt experiments without touching main configuration.

The creator spent 5 hours reconfiguring after the 4.5 update broke thumbnail and script generation agents, emphasizing that only those experiencing specific problems should upgrade. The Shipping School community (212 members after 23 days) provides live coaching on implementation, while Content Machine ($97 one-time) offers 10 AI agents for complete content automation.
