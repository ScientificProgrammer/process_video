# SUMMARY

JSF C++ coding standard demonstration showing how removing language features creates safer aerospace software through strict rules eliminating exceptions, dynamic memory allocation, and recursion for F-35 fighter jet programming.

# TECHNOLOGIES USED

- C++ programming language with JSF (Joint Strike Fighter) coding standard
- X-Plane 12 flight simulator
- Web API for real-time flight data streaming
- Python for GUI frontend development
- Custom Multi-Function Display (MFD) hardware
- Real-time data processing and calculation systems
- Embedded systems programming for aerospace applications

# TARGET AUDIENCE

- Aerospace software engineers and defense contractors
- Military aviation programs (US Air Force, Navy, international partners)
- Safety-critical systems developers
- Flight simulator enthusiasts and researchers
- Computer science students learning embedded systems
- Aviation industry professionals requiring certified software

# OUTCOMES

- Demonstrates practical implementation of JSF C++ standard for safety-critical aerospace applications through live flight simulation integration.
- Provides open-source educational repository showing compliant versus non-compliant code examples for learning purposes.
- Illustrates historical transition from Ada to C++ in military aviation software development and Pentagon approval process.
- Shows real-time data processing capabilities connecting flight simulator to custom hardware display using restricted C++ subset.
- Educates developers on memory safety, exception handling elimination, and recursion restrictions in mission-critical software environments.

# SOCIETAL IMPACT

Positive Impacts:
The project democratizes understanding of safety-critical software development by making JSF coding standards publicly accessible and demonstrable. It contributes to aerospace safety by promoting coding practices that prevent catastrophic failures like the Ariane 5 disaster. Educational value helps train future aerospace engineers in proper safety-critical development methodologies. Open-source approach fosters transparency in military software development practices, enabling broader community contribution and review.

Negative Impacts:
Focuses exclusively on military applications, potentially normalizing weapons systems development. May inadvertently provide technical insights useful for adversarial purposes despite using unclassified information. Creates perception that restrictive coding practices are only necessary in aerospace, potentially limiting adoption in other safety-critical civilian applications. Resource-intensive development approach may not be accessible to smaller organizations or developing nations.
