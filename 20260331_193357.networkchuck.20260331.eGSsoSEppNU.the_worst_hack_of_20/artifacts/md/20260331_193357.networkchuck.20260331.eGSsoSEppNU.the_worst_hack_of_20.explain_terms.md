# GLOSSARY OF TECHNICAL TERMS

## SUPPLY CHAIN ATTACK

A cyberattack that targets less-secure elements in the supply network of software or hardware rather than attacking the end target directly. Attackers compromise a trusted third-party component that many organizations depend on, thereby gaining access to all downstream users of that component.

- Analogy: Poisoning the water supply that feeds into an entire city rather than trying to poison each individual household's tap.
- Why It Matters: It allows attackers to compromise thousands or millions of systems simultaneously by exploiting the trust relationships in software dependencies.

## NPM (NODE PACKAGE MANAGER)

The default package manager for JavaScript and Node.js that allows developers to share and reuse code packages. It functions as a centralized repository where developers can publish libraries and download dependencies needed for their projects.

- Analogy: An app store for code snippets and tools, where developers shop for pre-built components instead of building everything from scratch.
- Why It Matters: It's one of the largest software registries in the world, making it a high-value target for attackers seeking maximum impact.

## DEPENDENCIES

External code libraries or packages that a software project requires to function properly. When you install one package, it automatically pulls in all the other packages it needs, creating a chain of trust.

- Analogy: Like ingredients in a recipe that themselves require other ingredients; making a cake requires flour, but flour production requires wheat.
- Why It Matters: The average project trusts hundreds or thousands of strangers with code execution through these dependency chains.

## PACKAGE.JSON

A metadata file in Node.js projects that lists all the dependencies, scripts, version information, and configuration details for a project. It serves as the manifest that tells NPM what to install and how to run the project.

- Analogy: A shopping list combined with an instruction manual that tells the package manager exactly what to buy and how to set it up.
- Why It Matters: Attackers can modify this single file to inject malicious dependencies without touching the actual source code.

## POSTINSTALL SCRIPT

An automated script that runs immediately after a package is installed via NPM, without requiring any user interaction or confirmation. These scripts can execute arbitrary code on the system with the same permissions as the user running the install command.

- Analogy: Like a program that automatically runs the moment you finish downloading it, before you even click to open it.
- Why It Matters: It provides attackers with an automatic execution mechanism that bypasses user awareness and many security controls.

## ACCESS TOKEN

A long-lived credential that grants programmatic access to perform actions on behalf of a user account, such as publishing packages to NPM. These tokens are used for automation and CI/CD pipelines but represent a single point of failure if compromised.

- Analogy: A master key that opens all the doors in a building and never expires unless manually revoked.
- Why It Matters: Compromising a single maintainer's access token can give attackers complete control over widely-used packages.

## CI/CD PIPELINE (CONTINUOUS INTEGRATION/CONTINUOUS DEPLOYMENT)

An automated system that builds, tests, and deploys code changes automatically when developers commit new code. These pipelines often automatically install dependencies, making them vulnerable to supply chain attacks.

- Analogy: An assembly line in a factory that automatically processes raw materials into finished products without human intervention at each step.
- Why It Matters: Automated pipelines can automatically pull and deploy compromised dependencies before humans have a chance to review them.

## REMOTE ACCESS TROJAN (RAT)

Malicious software that gives an attacker complete remote control over an infected computer, allowing them to execute commands, steal data, and monitor activity. Unlike simple viruses, RATs establish persistent backdoor access to compromised systems.

- Analogy: Installing a secret camera and remote control system in someone's house that lets a burglar come and go invisibly whenever they want.
- Why It Matters: RATs provide attackers with ongoing access to steal credentials, intellectual property, and conduct further attacks.

## COMMAND AND CONTROL SERVER (C2)

A server controlled by attackers that infected machines connect to for receiving instructions and sending stolen data. The C2 server acts as the command center for coordinating malware across multiple compromised systems.

- Analogy: A criminal headquarters where all the thieves report in for instructions and drop off their stolen goods.
- Why It Matters: Identifying and blocking C2 servers can stop malware from functioning, even if it's already installed on systems.

## DROPPER

A type of malware whose primary purpose is to install other malicious software onto a compromised system. Droppers are often small and inconspicuous, designed to evade detection while deploying the actual payload.

- Analogy: A lockpick that opens the door so the actual burglars can come in later with their tools.
- Why It Matters: Droppers allow attackers to keep the initial compromise small and undetectable while deploying larger, more sophisticated malware afterward.

## OBFUSCATION

The practice of deliberately making code difficult to understand by humans or automated analysis tools while maintaining its functionality. Attackers use obfuscation techniques like encoding, encryption, and code transformation to hide malicious intent.

- Analogy: Writing a threatening letter in a complex cipher or using elaborate metaphors so it looks like innocent poetry to casual observers.
- Why It Matters: Obfuscation allows malicious code to bypass security scanners and code review processes that look for suspicious patterns.

## XOR (EXCLUSIVE OR)

A bitwise operation commonly used in cryptography and obfuscation that compares two binary values and returns true only when the inputs differ. In malware, XOR is frequently used to encode malicious payloads because it's simple, fast, and reversible.

- Analogy: A simple substitution cipher where each letter is shifted by a specific amount, easily reversed if you know the shift value.
- Why It Matters: XOR encoding can make malicious code appear as random gibberish to security scanners until it's decoded at runtime.

## BASE64 (B64)

An encoding scheme that converts binary data into ASCII text format using 64 different characters. While not encryption, it's commonly used by attackers to disguise malicious code as innocent-looking text strings.

- Analogy: Converting a photograph into a long string of letters and numbers that looks like nonsense but can be perfectly reconstructed later.
- Why It Matters: Base64 encoding allows attackers to hide executable code inside text files that pass through security filters designed to block binaries.

## STATIC SCANNER

A security tool that analyzes code without executing it, looking for known malicious patterns, vulnerabilities, or suspicious constructs. Static analysis examines the source code or compiled binaries in their dormant state.

- Analogy: A security guard who inspects packages by looking at them and reading labels without ever opening them or turning them on.
- Why It Matters: Layered obfuscation can defeat static scanners because the malicious code is hidden until runtime when it decodes itself.

## CARET RANGE

A version specification in package.json using the caret symbol that allows automatic updates to minor and patch versions but not major versions. For example, ^1.14.0 will accept 1.14.1 but not 2.0.0.

- Analogy: Telling a store to automatically send you any improved version of a product as long as it's not a completely different model.
- Why It Matters: Caret ranges caused many projects to automatically pull the compromised Axios versions without explicit developer action.

## RELEASE BRANCH

A specific version line of software that receives updates and patches independently from other versions. Projects often maintain multiple release branches to support different major versions simultaneously.

- Analogy: Different editions of a textbook where the 5th edition and 6th edition both receive corrections, but in their respective versions.
- Why It Matters: Attackers poisoned multiple release branches to maximize the number of projects that would automatically pull compromised code.

## MAINTAINER

A person with elevated permissions to modify, publish, and manage a software package or project. Maintainers are trusted community members who review contributions and release new versions.

- Analogy: A building superintendent who has the keys and authority to make changes, let people in, and manage the property.
- Why It Matters: Compromising a single maintainer account can give attackers legitimate-looking access to publish malicious updates.

## OPEN SOURCE

Software whose source code is publicly available for anyone to view, modify, and distribute. Open source projects are typically maintained by volunteers and communities rather than paid employees.

- Analogy: A community cookbook where anyone can read the recipes, suggest improvements, and create their own versions.
- Why It Matters: Critical infrastructure often depends on unpaid volunteers, creating security risks when maintainers are compromised or projects are abandoned.

## HTTP LIBRARY

A software component that handles the technical details of making requests and receiving responses over the internet using the HTTP protocol. HTTP libraries abstract away the complexity of network communication for developers.

- Analogy: A universal translator that handles all the technical details of having a conversation in a foreign language so you can just say what you mean.
- Why It Matters: HTTP libraries like Axios are fundamental dependencies used by thousands of projects, making them high-value targets for supply chain attacks.

## DEOBFUSCATION

The process of reversing obfuscation to reveal the original, readable code or data. Malware often includes self-deobfuscation routines that decode themselves at runtime to execute their malicious payload.

- Analogy: A message written in invisible ink that becomes readable when you apply heat or the right chemical.
- Why It Matters: Self-deobfuscating malware can hide from static analysis but reveal its true nature only when executed.

## CREDENTIAL ROTATION

The security practice of systematically changing passwords, API keys, tokens, and other authentication credentials on a regular basis or after a potential compromise. Rotation limits the window of opportunity for attackers using stolen credentials.

- Analogy: Changing all the locks in your house after losing your keys or suspecting someone made copies.
- Why It Matters: After a compromise, rotating all credentials prevents attackers from using stolen authentication data to maintain access.

## REMEDIATION

The process of identifying, containing, and eliminating security threats from compromised systems, then restoring them to a secure state. Remediation goes beyond simply removing malware to include identifying what was accessed and preventing future attacks.

- Analogy: Not just removing burglars from your house, but also changing locks, reviewing security footage, inventorying what was stolen, and installing better alarms.
- Why It Matters: Proper remediation is critical after a supply chain attack because simply deleting files may leave backdoors and compromised credentials intact.

## TRANSITIVE DEPENDENCY

A dependency of a dependency; packages that your project doesn't directly use but are required by packages you do use. These create deep trust chains where you're implicitly trusting code you never explicitly chose.

- Analogy: Your friend's friend's friend who ends up at your party; you trust your friend, who trusts their friend, who brought someone you've never met.
- Why It Matters: Most security breaches in supply chains occur through transitive dependencies that developers don't even know they're using.

## NPM CLI (COMMAND LINE INTERFACE)

The terminal-based tool for interacting with NPM that allows developers to install packages, publish updates, and manage dependencies through text commands. The CLI provides direct access that can bypass web-based security controls.

- Analogy: The employee entrance to a building that has fewer security checkpoints than the public entrance because it assumes authorized users.
- Why It Matters: Attackers used the NPM CLI to bypass security guardrails that would have caught the malicious package through normal web publishing.
