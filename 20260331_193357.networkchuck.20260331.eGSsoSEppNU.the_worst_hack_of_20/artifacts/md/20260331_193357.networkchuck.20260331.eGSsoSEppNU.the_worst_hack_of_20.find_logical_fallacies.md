# FALLACIES

- Appeal to Fear: Informal Fallacy — Generating anxiety by claiming anyone could be infected to create urgency and alarm.

- Hyperbole: Informal Fallacy — Claiming this is the most dangerous command ever and most sophisticated attack in history.

- Hasty Generalization: Faulty Generalization — Concluding all npm installs are dangerous based on one compromised package incident.

- Appeal to Probability: Formal Fallacy — Assuming because infection is possible for anyone, it is probable for everyone listening.

- Slippery Slope: Informal Fallacy — Suggesting AI helping developers inevitably means AI helps hackers make attacks happen more frequently.

- Misleading Vividness: Faulty Generalization — Describing the attack in vivid detail to make it seem more prevalent than warranted.

- Argument from Repetition: Relevance Fallacy — Repeatedly stating this just happened and is dangerous without providing comprehensive statistical context.

- Appeal to Emotion: Red Herring — Using dramatic language about infection and danger to manipulate listener emotions over reasoning.

- Incomplete Comparison: Informal Fallacy — Claiming attacks happen more often now without providing historical data for meaningful comparison context.

- Proving Too Much: Informal Fallacy — The argument that npm install is dangerous could apply to all software installation.
