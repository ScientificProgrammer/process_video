# RECOMMENDATIONS

- Treat OpenClaw as incomplete software, not a finished product ready for deployment.
- Non-technical users should avoid installing OpenClaw until security issues are resolved.
- Sandbox AI agents using VPS or separate Mac Mini to isolate vulnerabilities.
- Monitor AI agent activity constantly to ensure it's performing intended tasks correctly.
- Set spending limits on API tokens to prevent hundreds in unexpected costs.
- Never give AI agents full system access to your primary computer.
- Avoid granting AI agents access to email accounts due to prompt injection risks.
- Don't provide AI agents with browser access to prevent scam susceptibility issues.
- Secure all API keys separately to prevent exposure through prompt injection attacks.
- Regularly verify AI agent behavior as reliability changes unpredictably over time.
- Understand that LLMs cannot distinguish between user data and control instructions.
- Recognize every email and message becomes an attack surface with AI agents.
- Remember AI agents are "idiot savants" without consistent worldviews or truth understanding.
- Switch to cheaper LLM models like Sonnet instead of expensive Opus versions.
- Expect AI agents to break unexpectedly even after weeks of reliable performance.
- View AI agents as experimental technology requiring constant human oversight and intervention.
- Protect sensitive data by limiting what information AI agents can access remotely.
- Research prompt injection vulnerabilities before deploying any AI agent with system access.
